# 动作编排与物理连续性

## 最小动作链
起点（站位/持物/速度）→推动动作（谁主动、动作路径）→接触点和受力→结果（位置、姿态、物体状态）。只有剧情要求接触时才安排接触；快动作在一个时间段内连续完成，不拆成多段让演员等待。

## 典型场面
| 类型 | 需要交代 | 易犯错误 |
| --- | --- | --- |
| 拳脚对抗 | 双方位置、出招肢体、接触点、受力方向、后退或格挡 | 出拳者突然换手，被击方提前倒地 |
| 兵器碰撞 | 刃口/尖端、握法、轨迹、碰撞点、反弹方向 | 武器飞行前后缘颠倒 |
| 追逐 | 移动方向、速度连续性、背景视差、障碍位置 | 追逐者停下等另一人完成动作 |
| 腾空/落地 | 起跳支点、身体朝向、空中轨迹、着地点 | 失重悬停后凭空切回站姿 |
| 取放道具 | 初始持有人、接触次序、目标表面、最终位置 | 道具突然消失、变形或换手 |
| 门/机关 | 铰链或滑轨方向、手的接触点、开关末态 | 门向相反方向折叠，按钮操作状态混乱 |

## 时间安排
5 秒镜头适合一个连续的主动作+即时反应。连续动作不应因为分段标题人为停住；复杂多招对打应由编剧拆成多个视频节点。必要时只保留决定胜负的一个接触瞬间。

## 与摄影结合
人物高速移动时先确保身体和接触点留在画幅内，再考虑跟拍。不要让快速横移同时发生大角度环绕和特写切换。摄影机保持单一路径。

## 复杂动作拆成镜头内可读的事件

| 场面 | 保住的动作链 | 摄影与声音 | 常见失败 |
| --- | --- | --- | --- |
| 短兵器格挡 | 攻方从原握位劈下，守方保持支点把兵器移入同一路径，两者在胸前外侧接触，攻方刃口沿接触面滑开 | 侧前中全景，碰撞声随接触 | 剑先交叉停住，之后才触发攻方挥动 |
| 绊截与倒地 | 跑者原速进入，绊截者贴地短探，踝部接触后跑者上身沿前进方向继续并失去支撑 | 固定侧位看见脚和上身 | 跑者先停步等脚伸出，或支撑脚无故换边 |
| 跃过障碍 | 支撑脚蹬地，质心越过已知障碍，朝约定方向落在可见支点，再屈膝承重 | 保留起跳与着地，落地声随脚触地 | 近景看不见落点，腿部凭空回到站姿 |
| 双人夺物 | 物件与两人起始握位明确，一方施力，另一方支点随阻力改变，剧本指定的手最后松开 | 把手和重心一起留在画面 | 各段反复写抢夺，持有人每段重置 |
| 弹道或投掷 | 道具从指定手或装置脱离，前缘朝路径，越过明确参照，撞击或出画符合剧情 | 用斜侧构图区分出发点与落点 | 中途翻转刃口或跳到新落点 |
| 连续越障追逐 | 每人沿同一既定方向通过障碍，第一人落地继续，第二人保持自己的连续节奏 | 侧跟或固定斜侧机位 | 为了展示两次动作强制第一人停在落点 |

**镜尾取舍**。若本镜目的是破防，结束在守方失去保护位置并仍持有兵器的状态；后续反攻留给已有下一镜。若本镜要求格挡成功，镜尾应让观众看清防线仍成立。伤口、道具损坏与站位变化以剧本给定的末态为准。
