# 人物表演、眼神与微动作

## 表演按因果推进
选择“刺激→注意→反应→行动”链条中当前镜头真正包含的部分。一个短镜头一般只承载一个主要情绪转折；用少量动作表达，不要把所有五官写成持续夸张运动。

| 剧情/情绪 | 首选可见动作 | 常见误写 |
| --- | --- | --- |
| 怀疑 | 视线从对方移向异常细节，轻微偏头 | 反复挑眉、无理由看镜头 |
| 震惊 | 呼吸短暂停住，眼睛聚焦，身体重心轻微后退 | 长时间瞪大双眼僵住 |
| 压抑愤怒 | 下颌收紧、指尖逐渐收拢、目光不移开 | 全程握拳颤抖、大喊 |
| 紧张 | 胸腔呼吸变浅、手指暂停、注意声音来源 | 不断环顾四周却无对象 |
| 轻蔑 | 视线短暂掠过对方后回到手中物件 | 永远歪嘴一笑 |
| 迟疑 | 手靠近道具稍停，目光核对对方反应 | 多次重复伸手与缩手 |
| 松一口气 | 肩膀放松、呼气、手掌摊开 | 角色一直保持快乐表情 |

## 对话表演
每句台词确认说话人的朝向、嘴部口型、受话对象及同场听者的反应。不说话的人可以视线、呼吸、抬手回应；保持其嘴部闭合，避免无意义对口型。台词要匹配时长，叙事意图与剧本确定文本优先。

## 身体/接触动作
描述身体重心支撑、接触点与受力方向。人物递物：起点在谁手里→手靠近→物体接触另一只手→松手→结束持物关系；不要突然跳转持有人。微动作不必附会额外动机。

## 防机械感
角色未被剧情要求直视镜头时，默认看向当前交谈者、正在操作的物品或威胁来源。描述自然的眼神转移与短暂注意停留，避免连续眨眼、反复点头、所有人同步动作。

## 用同一种情绪表达不同意图

| 意图 | 刺激与动作节拍 | 适用画幅 | 易误写 |
| --- | --- | --- | --- |
| 掩饰恐惧 | 听见近处脚步，手先按住桌缘，抬眼后保持说话朝向，指节的压力短暂加重 | 侧前中近景同框保留脸和手 | 边说话边连续环顾，丢失交谈对象 |
| 压住反驳 | 听者吸气准备开口，随后合唇，视线落在说者手边 | 双人中景或听者近景 | 把未说出口的句子写成对白 |
| 心虚转移注意 | 被点名时眼神短暂偏向已知物件，随即回到说者 | 保留视线目标的斜侧中景 | 添加未设定的藏匿道具 |
| 疲惫中强撑 | 身体支在已有扶手上，起身前掌根发力，站直后呼吸仍偏浅 | 中全景读支点与重心 | 用颤抖、流泪、跪倒同时说明疲惫 |
| 情绪回落 | 听见确认后，吐气，拇指松开紧捏的物件边缘，目光维持在对方身上 | 中近景读肩颈和手 | 让角色突然换成笑脸 |
| 突然认出熟人 | 注意力从行进方向移到对方脸上，步幅短暂缩小，未开口时嘴部闭合 | 中景读步态，近景读眼神 | 对方还没出现就提前做出反应 |

## 多人表演的主次

给刺激的发起者一个清楚动作，主要反应由剧情指定的人承担。同场其他人保持正在做的事，或只在自己有理由察觉时变化。交接或搀扶先给主动手与支点，再写受力方转移重心。镜尾注明谁站在哪里、谁还握着物件。短镜中每人一个主反应通常足够。

**示例**。角色把钥匙递给同伴但迟疑。镜头保持斜侧中近景，两手与受领者视线同框。持有者伸手时视线先核对同伴，钥匙碰到对方掌心后手指才松开。若剧本要求最终收回钥匙，就在接触前止住，末态明确钥匙仍由原人握住。
