# 人物表演、眼神与微动作

## 表演按因果推进
选择“刺激→注意→反应→行动”链条中当前镜头真正包含的部分。一个短镜头一般只承载一个主要情绪转折；用少量动作表达，不要把所有五官写成持续夸张运动。

| 剧情/情绪 | 首选可见动作 | 常见误写 |
| --- | --- | --- |
| 怀疑 | 视线从对方移向异常细节，轻微偏头 | 反复挑眉、无理由看镜头 |
| 震惊 | 呼吸短暂停住，眼睛聚焦，身体重心轻微后退 | 长时间瞪大双眼僵住 |
| 压抑愤怒 | 下颌收紧、指尖逐渐收拢、目光不移开 | 全程握拳颤抖、大喊 |
| 紧张 | 胸腔呼吸变浅、手指暂停、注意声音来源 | 不断环顾四周却无对象 |
| 轻蔑 | 视线短暂掠过对方后回到手中物件 | 永远歪嘴一笑 |
| 迟疑 | 手靠近道具稍停，目光核对对方反应 | 多次重复伸手与缩手 |
| 松一口气 | 肩膀放松、呼气、手掌摊开 | 角色一直保持快乐表情 |

## 对话表演
每句台词确认说话人的朝向、嘴部口型、受话对象及同场听者的反应。不说话的人可以视线、呼吸、抬手回应；保持其嘴部闭合，避免无意义对口型。台词要匹配时长，叙事意图与剧本确定文本优先。

## 身体/接触动作
描述身体重心支撑、接触点与受力方向。人物递物：起点在谁手里→手靠近→物体接触另一只手→松手→结束持物关系；不要突然跳转持有人。微动作不必附会额外动机。

## 防机械感
角色未被剧情要求直视镜头时，默认看向当前交谈者、正在操作的物品或威胁来源。描述自然的眼神转移与短暂注意停留，避免连续眨眼、反复点头、所有人同步动作。
