# 摄影语言与空间调度

## 先维护空间连续性
先定摄影机站位、主体朝向、相对遮挡、视线对象和景深层次；镜头移动时它们必须持续可追踪。人物谈话优先维持视线轴与左右站位。镜头不必总保持同一种角度：场景跨镜的轴线变化应交由分镜规划，单镜头内部的摄影机运动要连续。

## 按叙事目的选景别
| 景别 | 主要用途 | 易错点 |
| --- | --- | --- |
| 大远景/远景 | 建立地点、距离、角色力量悬殊 | 人物细表情难读，少写精细眼部动作 |
| 全景 | 展示身体行动、道具互动、人物相互距离 | 背景过载导致主体不清 |
| 中景/中近景 | 对话、明确视线与双手互动 | 人物常被安排无目的地站定 |
| 近景/特写 | 情绪转折、物体局部、关键反应 | 同时要求全身打斗会互相矛盾 |
| 极特写 | 眼睛、指尖、细小机关 | 小特征必须符合参考图与镜头主体 |

## 机位与构图选择
- 平视让人物反应直观；轻微低机位可凸显压迫；高机位表现人物在空间中受制，但不能直接等同某种情绪。
- 对称构图适合秩序、仪式、压迫；偏置和负空间适合等待、未知威胁。使用前景遮挡或引导线时，须指向剧情主角而非增加装饰。
- 两人物镜头需定义谁在前景、谁被遮挡、谁注视谁，明确谁说话。保持动作连续，避免把正反打写到单个镜头里。
- 景深只服务聚焦：需要交代空间关系时用较深景深；突出微表情或物件时才浅景深。

## 镜头描述最小信息
“画幅内的主体+景别+机位+主体相对位置/朝向+焦点对象+一种稳定或移动的摄影方式”。需要时再增加镜头前景、中景、远景层次，不用每条都填完所有摄影术语。

## 视点如何改变观众知道的事

| 机位 | 选择依据 | 执行边界 |
| --- | --- | --- |
| 平视双人 | 要读到同一时刻两人的反应 | 肩线与视线分开，保留谈话对象 |
| 同侧越肩 | 观众需贴近一方判断，另一方仍可见 | 近肩只占边缘，露出受话者嘴和眼 |
| 斜低位 | 门洞、台阶或高差已经是压力来源 | 留脚下支点或与场景的关系，避免大仰角遮脸 |
| 斜高位 | 交代退路、包围或障碍 | 让主体和出口同框，面部微动作改由身体体现 |
| 鸟瞰 | 围阵、岔路或队列形状本身是信息 | 明确地面图形、行进方向和比例参照 |
| 倾斜地平线 | 剧情存在失衡、坠落或视点失稳 | 倾斜方向与已知重力及动作一致，保持主体方位可辨 |

## 轴线案例

两人隔着桌子交接证物，上一镜人物甲居左、乙居右。若当前镜头重点是持有人变化，用桌面斜侧中景让甲右手、物件、乙左手沿同一动作线可见，并保留甲乙的左右关系。若重点是乙读懂物件，已完成交接时可以取乙的同侧近景。机位绕到另一侧会交换左右，对已有位置关系关键的交接会更难读。
