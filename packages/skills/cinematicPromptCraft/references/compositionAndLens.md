# 构图、焦段与镜头焦点

## 构图方法
- 三分法：角色落在画面三分之一位置，视线前方留出空间；适合观察、等待或方向性运动。
- 对称：主体与门、实验台、王座等场景轴线一致；适合仪式与压迫，避免无意义地每镜都居中。
- 框中框：门框、窗、设备形成二级画框，凸显被观察者；框必须是场景已经存在的物件。
- 前中后景：前景道具明确叙事原因，中景主体表演，远景交代风险或空间；说明遮挡边界。
- 引导线：走廊、桌缘、光束可指向关键主体；避免凭空创造新建筑元素。
- 顶视：需要读清人物位置、物件或动作时，可略微倾斜为斜俯，仍保留从上向下的空间关系。

## 焦段语言
- 广角感：增强纵深与运动速度；近距离人物比例容易夸张。
- 标准焦段感：自然的脸部形变与距离关系，适合多数人物戏。
- 中长焦感：收紧背景、隔离目光与物件，适合情绪细节；不适合大量空间信息。
- 微距感：仅在物体纹理/指尖极特写使用；同时要展示全身动作会自相矛盾。

镜头语言不能凭空重写已批准原画的物理比例、道具结构或场景布局。若参考图确定主构图，优先沿用参考关系。

## 让焦平面承担信息顺序

| 画内任务 | 构图与焦点 | 需要避免 |
| --- | --- | --- |
| 看见两人争夺同一物件 | 三者呈斜线，手和物件处于相近纵深，景深覆盖接触区 | 极浅景深让一只手或持物交接糊掉 |
| 暗示入口将有人经过 | 人物偏置，朝入口留白，门框保留可辨轮廓 | 留白指向错误方向，观众等错位置 |
| 表达被阻断的行进 | 以已有障碍横截运动方向，保留障碍边缘与可绕行区域 | 前景装饰遮住发生受力的部位 |
| 让物证出现 | 同一构图中由手移开遮挡，或在两个不同距离的对象间转焦 | 同时变焦、改变机位和换焦，揭示原因模糊 |
| 保留人物与危险的距离 | 侧向全景或斜侧深景，地面线和场景锚点连接双方 | 长焦视点把必须区分的前后距离挤在一起 |

焦段、机位距离和景深分别描述。需要长焦感时同时给出远处机位和收紧的背景关系。保持画幅比例和脸型要求优先于毫米数。近距离广角只在空间夸张属于表达目的时使用。

**镜头实例**。狭窄通道里角色停在门前。要交代退路，用走廊轴线侧方的斜侧中全景，让门和后方通路同时可读。要交代角色听见门内声响后的迟疑，用固定中近景，门缘仍在视线方向，手在门把前停住。
