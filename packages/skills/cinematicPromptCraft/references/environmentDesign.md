# 场景、环境和镜内空间

## 场景三层
- 不可更改：已批准场景的建筑结构、门窗数量、通道方向、主要设备和道具拓扑。
- 可用于叙事：已有走廊纵深、桌面高低、窗外天气、远近遮挡、人物可行走空间。
- 可选氛围：符合既有设定的薄尘、轻雾、空气中的湿度感、音响空间；不能用氛围替换实际场景结构。

## 场景类别的摄影关注点
| 类别 | 重点 |
| --- | --- |
| 狭小室内 | 摄影机可站的位置、门口遮挡、近距离焦段形变 |
| 实验室/控制室 | 仪表与观察目标、桌面连接关系、已有光源、设备实际尺寸 |
| 城市街道 | 人车动线、反射来源、可见路口方向、天气持续性 |
| 古代殿堂 | 柱廊尺度、人物相对轴线、主光透入方向 |
| 森林/山地 | 前后景树体遮挡、地形坡度、风向与衣物摆动 |
| 地下洞穴 | 光源有限、岩壁纹理、声响回声、地面支撑点 |
| 星空/异世界 | 地平线、重力线索、主体参照物与固定世界规则 |

## 建立镜与环境反馈
建立镜优先交代主体在什么空间、空间如何影响行动。环境出现变化时明确是现有物件响应（灯闪、尘落、玻璃微振），不能凭空增加无关人物或建筑。若原画是多视角拼版，成片只选择与当前摄影位置匹配的单一空间视角。
