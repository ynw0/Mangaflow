# 场景、环境和镜内空间

## 场景三层
- 不可更改：已批准场景的建筑结构、门窗数量、通道方向、主要设备和道具拓扑。
- 可用于叙事：已有走廊纵深、桌面高低、窗外天气、远近遮挡、人物可行走空间。
- 可选氛围：符合既有设定的薄尘、轻雾、空气中的湿度感、音响空间；不能用氛围替换实际场景结构。

## 场景类别的摄影关注点
| 类别 | 重点 |
| --- | --- |
| 狭小室内 | 摄影机可站的位置、门口遮挡、近距离焦段形变 |
| 实验室/控制室 | 仪表与观察目标、桌面连接关系、已有光源、设备实际尺寸 |
| 城市街道 | 人车动线、反射来源、可见路口方向、天气持续性 |
| 古代殿堂 | 柱廊尺度、人物相对轴线、主光透入方向 |
| 森林/山地 | 前后景树体遮挡、地形坡度、风向与衣物摆动 |
| 地下洞穴 | 光源有限、岩壁纹理、声响回声、地面支撑点 |
| 星空/异世界 | 地平线、重力线索、主体参照物与固定世界规则 |

## 建立镜与环境反馈
建立镜优先交代主体在什么空间、空间如何影响行动。环境出现变化时明确是现有物件响应（灯闪、尘落、玻璃微振），不能凭空增加无关人物或建筑。若原画是多视角拼版，成片只选择与当前摄影位置匹配的单一空间视角。

## 场景组织实例

- **狭窄电梯或车厢**。先确定唯一通行方向与近端遮挡。人物进出时保留门口和脚下支点，威胁镜用门内外的反光或脚步提供来向。狭窄空间里大幅环绕会让视点穿过墙面。
- **雨夜街道**。把雨滴、路面倒光、伞缘和行进方向放在同一个已建立的街面。追逐时用侧跟让路缘与门面依次掠过。拐弯以后以实际相邻镜头确定出画方向。
- **古建筑大殿**。可沿柱廊建立人物与出口、台阶的关系。低机位突出位阶时仍露出踏步与脚下支点。使用已确认的建筑光源，人物横移后阴影继续沿原方向变化。
- **山地或森林**。先确定坡向及可行走路线。脚底受力、前景树木掠过和衣摆随风同向，给出连续空间。危险可用既有视线遮挡揭示，避免让林木突然重排。
- **地下洞穴**。暗部保留近处地面轮廓和既有岩壁，移动光束照亮具体表面。窄道回声与开阔洞腔的声音距离有别。若镜头用途是定位出口，画内需有可确认的地形或光源。
- **奇幻浮空地形**。如果设定明确重力异常，先用已批准的台面、坠落物或衣摆确定局部方向，再表现人物移动。没有可比尺度的雾和光点难以说明空间关系。
