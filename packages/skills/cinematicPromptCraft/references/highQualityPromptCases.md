# 高质量视频提示词案例库（影视导演参考）

版本：1.0.0（2026-11-10）。供 video-director / cinematicPromptCraft 按需查阅，不是替代 H3 官方格式的系统指令，不是“验证成功的真实生成结果”。

- A｜Google DeepMind Veo 官方 Prompt Guide：https://deepmind.google/models/veo/prompt-guide/ —— 主体、构图、动作、镜头、灯光和声音具体描述。
- B｜fal H3 教程：https://fal.ai/learn/tools/minimax-h3-explained —— 赋予每种参考独立任务、分段描述运动与声轨；其案例面向对应 API，参数不能直接套到本机 ComfyUI。
- B｜H3 社区公开案例索引：https://github.com/akirakai/awesome-minimax-h3-prompts —— 仅用于发现参考，不能假定社区案例已独立复现。
- 下文 V01–V09 全部是为 MangaFlow **原创、待生成验证的示范**，并非上述网站的原提示词或已获 QC 通过的真实样片；所有动作、场景需替换为当前批准资产与剧情。

## 外部公开优质案例
需要对照真实已发布提示词和输出示例时，先读 [publicPromptCaseIndex.md](publicPromptCaseIndex.md)；其中有 Runway、Veo 和 H3 供应商公开演示的原始链接、可借鉴技法与模型适配限制。这些公开案例没有经过本机同工作流复验。

## 检索与用法
1. 按当镜 intent、scene/action/performance/camera、时长、ref mode、可见锚点定位，优先匹配“难题类型”，再匹配视觉风格。
2. 一次最多阅读 1–3 条。每条只迁移“动作因果、可见构图、运镜策略、声画对应”，不迁移人物、道具外形、对白或参考绑定。
3. 若案例与镜头合同、已批准素材、模型输入模式或时长冲突，直接放弃案例，不能反向改合同。
4. 以下为**导演提示词内核**，不直接作为模型全文。Ref2VA 仍由 h3-prompt-writing 编译为 subject_definitions / summary / retention_analysis / detailed_description / overall_soundscape / non_diegetic_music；必须保持当前项目每条视频节点**一个连续摄影镜头**。时间片是同一镜头中的行动节拍，不是切镜。审稿仅依据实际 prompt 和合同，不依据案例好坏。
5. 复用后保存 source_case_id、使用位置、变更点；成片 QC 后才能记 success 或 failure。默认 evaluation=pending，严禁把“精心设计”写成“已验证”。

## V01｜欠债压迫：两人对峙与道具交接
tags: intent=dialogue; scene=谈判/质问; emotion=压迫; camera=固定机位; duration=5-7s; references=角色+场景+欠条。
前提：欠款者右手按着账本，催债人把纸质催款单推到其面前；同框看到两人、账本、纸张，单镜完成。
示范导演核心：侧前方固定双人中景，靠镜头一侧为工作台；左侧催债人的右手把折起的催款单沿桌面推到右侧主角的账本边缘，纸张接触账本发出轻响。主角先看催债人，再垂眼看纸张，右手仍压着账本，停止翻页；镜尾单据停在账本旁、两人位置不变，听到旧车间的低风扇声。
动作节拍：0–1s 保持对峙，1–3s 推纸并抵达，3–5s 主角视线下移和手部停顿。
易错：单据瞬移、眼神正视摄影机、镜头推进到看不见接触点。验收：推送方向与落点可见，纸张位置在镜尾可继承。

## V02｜主角无声反应：系统提示突现
tags: intent=reveal; scene=觉醒/反应; emotion=惊疑; camera=固定机位; duration=5s; references=主角+手机/界面+场景。
前提：手机屏幕出现剧情允许的发光界面，角色没有对白。
示范导演核心：稳定肩后中近景，手机位于画面下方前景，人物右侧轮廓仍可见。屏幕内已设定的系统标识从暗到亮，冷光先落在指节与下颌；主角准备滑动的拇指停在屏幕边缘，视线落在屏幕中心。最后一秒保留屏幕可读区域、悬停拇指与人物侧脸，房间环境声继续。
易错：凭空新增未批准 UI、屏幕文字乱码、角色直接朝镜头大喊。验收：人物因果反应发生在发光之后。

## V03｜旧车首次展示：电影级车身质感
tags: intent=reveal; scene=登场/场景建立; emotion=哀伤/希望; camera=缓慢拉开; duration=5s; references=旧车+车间。
前提：旧车与室内灯光取自批准图；本镜任务是展示车的旧而可靠，不做变形。
示范导演核心：45 度斜前中景起幅，镜头沿车头外侧缓慢后移一小段，露出车头与前轮。顶棚单侧暖工作灯沿钣金起伏形成不均匀狭长高光，已有划痕与氧化纹理保持清楚；空气中稀薄悬尘在灯束内缓缓漂浮。镜尾完整保留车头轮廓与车间地面接触阴影。
易错：模型自发修复为崭新超跑、车标结构变更、绕车一整圈超出 5 秒。验收：车辆轮廓与原图可比、轮胎接地。

## V04｜机翼展开：可追踪机构
tags: intent=mechanical; scene=机械变形; action=旋转/伸缩/锁定; camera=固定机位; duration=5-7s; references=道路模式+中间态+展开态。
前提：批准的道路模式和机翼结构图中，铰接点、翼片归属、两侧数量能对应；仅用普通 Ref2VA 参考图时不可声称画面严格对齐给定末帧。
示范导演核心：固定车侧斜后中全景，确保车顶、左右翼根与路面同时可见。车顶预留面板沿既定后缘铰链向上翻开，内侧左右翼片各自沿已定义滑轨从车身侧上部伸出，分别绕翼根转到水平位置；锁扣在翼片停止旋转后依次闭合。车轮与驾驶室始终不变；光线在真实金属转轴与翼片棱边上移动。伴随面板摩擦、短促伺服声和两次清脆锁止声。最后留 0.7s 看到两翼处于已批准的展开末态。
易错：无来源长出第三片翼、左右翼互换、过程突然切到空中、镜尾还在运动。验收：起点/铰链/行程/锁定前后连贯，车窗和车轮身份不漂移；拥挤时将左右翼拆为两个独立镜头。

## V05｜银隼道路行驶：速度的物理证据
tags: intent=action; scene=追逐; action=行驶/转向; camera=侧向跟拍; duration=5s; references=车辆+道路。
前提：只拍车辆沿路疾驶，不改变车型、不展开机翼。
示范导演核心：车外低机位侧向跟拍，与汽车同速向前；主体保持画面中前部，路侧树影与路面划线稳定向后移动。悬架对路面接缝有轻微压缩回弹，轮胎持续接触路面，车侧漆面掠过树影和路灯反射。车轮摩擦与风声同步增强，尾段车辆轻微前冲但不离开画面。
易错：轮子停止转动、背景不动、车身漂浮或变成玩具比例。验收：移动参照系、轮胎与地面交互一致。

## V06｜第一次离地：有重量的飞行
tags: intent=action; scene=装置启动/揭示; action=离地; camera=低机位; duration=5s; references=机翼展开车+空旷道路。
前提：机翼已在上镜完全展开；若当前镜仅负责起飞，不能再次安排整套变形过程。
示范导演核心：机位固定在斜前方路边低处，完整收住车轮与展开机翼。车体首先轻微俯仰，离地前轮胎对路面承压；随后四轮逐渐与地面拉开可辨距离，车下尘埃受下洗气流向外扩散，车身缓慢升至略高于路肩。镜尾稳定悬浮，翼片与车顶仍保持相同连接关系；低频电机轰鸣在离地一刻上扬。
易错：瞬移到云层、脚下无参照、道路模式与飞行模式混合。验收：能一眼认出“离地发生了什么”。

## V07｜对白+反应：说话人与听话者分离
tags: intent=dialogue; scene=告别/反转; performance=对话口型/沉默反应; camera=固定机位; duration=6s; references=双角色+桌面。
前提：具体对白由合同提供，时长应容纳完整台词，S1/S2 与 Subject 编号绝不相互代替。
示范导演核心：固定轴线同侧的双人中景。左侧人物 (S1) 看着右侧人物说完本镜合同原台词，发声时嘴唇明确动作；右侧人物全程闭嘴，先凝视说话者，再低头看桌面自己的钥匙。句末左侧人物闭嘴，右侧人物轻轻把钥匙压在桌面；桌面接触声与指尖到达同刻，镜尾两人和钥匙同框。声音默认按项目批准的约 1.5 倍正常语速，仍以可说完且口型可跟踪为准。
易错：S2 被误用作 Subject 2、两人同时动嘴、对白在最后一秒挤出。验收：台词逐字一致，声源与口型绑定，沉默者始终闭嘴。

## V08｜特效有传播路径：设备能量启动
tags: intent=effects; scene=装置启动; effect=电弧/脉冲; camera=固定机位; duration=5s; references=装置+工作台。
前提：设备已有可见发光点和供能通路，不能新增凭空的第二设备。
示范导演核心：固定斜侧近景同时收住供电接口、控制按钮与金属外壳。角色按下按钮后，一条细窄蓝白亮线从接口沿既有表面导线传至外壳边缘；电弧在连接点闪过一次并反射到旁边扳手，后沿原路径迅速减弱。保留先按键、后传播、再光线消失的因果，环境底噪不变，电弧短促劈啪声只在发生时听见。
易错：满屏发光遮蔽设备、特效无来源、按钮未触碰就通电。验收：源头/路径/反馈/消退均可见。

## V09｜FL2VA 首尾帧之间的物理动作
tags: intent=mechanical; scene=机械变形; action=折叠/锁定; camera=固定机位; duration=5s; references=严格首帧+严格末帧。
前提：实际选中 FL2VA 工作流，已确认首尾帧均作为真实控制输入；不能用普通 Ref2VA 冒充。
示范导演核心：以第一张已批准展开态机翼图为准确起幅，保持汽车在同一机位与地面位置。左右翼片沿固定铰链反向旋转，伸缩段依次沿导轨向车身收回，车顶盖板最后闭合，锁扣落位；车窗、轮组、颜色、反射方向始终连续。每个可见部件逐步趋向末帧已批准道路状态，在最后 0.7s 落定至末帧同构图。
易错：重画车身替代真实折叠，末帧不能对齐，两帧构图不同却强行插值。验收：首末状态、相机、机构映射一致。

## 案例反馈登记格式
case_id / shot_id / input_mode / input_refs / workflow_name / duration / changed_prompt_span / QC_observations / failure_class / rework / recheck_result / source_link_or_local_video / evaluation。
failure_class 只从 identity_drift、geometry_error、motion_error、camera_error、lip_sync、audio_error、timing_error、asset_issue 中选择有证据的项。尚未生成 = pending；未完成复验 = unverified；模型质检有真实日志且符合全部镜头硬要求才记 passed。禁止将示范案例本身写成已验证结果。
