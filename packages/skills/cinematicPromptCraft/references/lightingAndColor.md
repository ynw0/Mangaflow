# 光影、色彩与视觉可读性

## 光源优先于形容词
- 主光：来自哪一方向、落在哪个物体上、色温与硬软、是否被遮挡。
- 环境填充：现有室内灯、天空散射或窗口反光对暗部的贡献。
- 轮廓与高光：有现实/剧情来源才添加；金属反射须对应光源和材质。
- 特效自发光：确定强度范围与照射对象，不能额外凭空增加摄影棚灯。

## 氛围映射
| 目标 | 可拍摄表达 | 忌用泛词 |
| --- | --- | --- |
| 冷静/理性 | 冷白顶光、清晰设备轮廓、低对比环境反射 | “高级电影质感” |
| 压迫 | 背景略暗、角色与大体积建筑形成尺度差 | 无来源的黑雾 |
| 秘密被发现 | 面部保留暗部层次，局部物件反射吸引视线 | 突然全场泛金光 |
| 温暖/安全 | 侧向暖光、柔和阴影过渡 | 暖色滤镜覆盖所有材质 |
| 危险逼近 | 远处光源出现节律变化、局部反射移动 | 与剧情无关的警报灯 |

## 连贯性
同场次已确认主光方向、时间和天气不能每镜随机改变。逆光产生轮廓亮边时，面部曝光由环境填充解释；镜面/金属倒影必须对应场景现存物体。动态特效可改变局部照明，但镜头结束回到合理环境光。

## 将光色写成同场因果

| 条件 | 观察顺序 | 容易失效的写法 |
| --- | --- | --- |
| 窗口侧光中的对话 | 窗侧脸颊先亮，另一侧由房内漫反射维持层次；演员转向时阴影随之移动 | 台词一响整屋突然变色 |
| 明暗间跨步 | 门内外亮度已建立，角色身体依次进入亮带，衣料反射最后稳定 | 把角色亮度变化写成灯源位移 |
| 金属证物 | 指定已有灯源，转动物件时高光沿外缘移动，关键纹理保持可辨 | 强反光覆盖要揭示的刻痕 |
| 局部脉冲 | 发光物先亮，近处皮肤与台面出现短时反光，远处原光源继续 | 整个场景一起过曝，主体轮廓丢失 |
| 双光源冲突 | 区分稳定背景光与短时局部光的作用对象，以主要动作的可读性定主次 | 每个时间段改变主光方向，造成空间跳变 |

**对比示例**。人物第一次触碰异常物件，冷色反射从指腹扫到下颌即可标出变化。若剧情主信息是走廊照明熄灭，则保留走廊远处原有发光区域和近处人物轮廓，亮度变化从实际灯位开始。两种设计的光源不同，选能交付剧情信息的一种。
