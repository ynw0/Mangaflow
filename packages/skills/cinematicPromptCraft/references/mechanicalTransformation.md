# 机械变形与结构连续性

适用于机甲变形、机械折叠、同一装置在镜内重组。先确定观众要看清哪一次结构变化，再安排景别、变形顺序和末态。

## 先核对参考状态

- 以批准的身份和结构为基准，把起始、中间、末态列成同一个主体的状态。Picture 编号跟实际连线走，Subject 编号跟身份走。
- 对每个决定身份或动作的零件，核对来源、连接点、旋转轴或滑动方向，以及结束位置。例如胸部车窗连同胸甲绕下沿转轴向前翻成驾驶室前窗。参考图里必须能对应到同一块窗体。
- 若中间态出现无法追溯来源的车轮、关节换边或零件数量不同，返回素材准备修正。形变中被车身盖住的部件仍有去向，末态应保持该遮挡关系。
- 普通全参槽提供身份和状态信息。只有当前工作流实际绑定首帧或尾帧时，才能把相应图片当作固定帧。对普通参考里的中间态，可以安排一个可读的经过状态。

## 选择可看清的运动链

| 结构变化 | 写清的运动 | 审核证据 |
| --- | --- | --- |
| 面板折叠 | 已有转轴、板边的运动方向、末端扣住的位置 | 运动前后能追踪同一块面板 |
| 伸缩或滑移 | 套筒或滑轨的位置、移动部件和止点 | 行程沿既定轴线，连接处持续可辨 |
| 轮组展开 | 轮组从哪个部件露出、绕哪个关节翻转、落到哪里 | 车轮来源、数量与地面接触可辨 |
| 机身合拢 | 两块对应结构的接触边、对齐顺序、接触声 | 合拢时保留两侧来源，末态边界接齐 |

短镜优先交代少数能看清的主动作。把稳定外形集中在主体定义，时间段只写该段改变的部件。主结构锁定后给末态留出可观察时间。若剧本要求的多处精细运动在给定画幅和时长内无法同时看清，返回 blocked 并标出冲突动作。

## 示例

机器人变成卡车的画面任务是让观众看懂驾驶室如何形成，再认出完整卡车。使用同一街道的固定斜前中全景。先让机器人屈膝降低重心，胸甲和车窗从已有转轴向前翻成车头，再让腿侧已有轮组翻出接触路面。手臂随躯干侧面收进车身，连接点仍在画幅内。镜尾等车身停稳，露出驾驶室前窗和已展开的车轮。合拢声和轮胎落地声放在实际发生的时间段。
