# 按剧情意图选择拍法

每条方案都只是一个**可选导演策略**；先对照剧情、参考图和场次连续性，再选，不允许把方案里没有依据的道具/特效加进成片。

| 剧情意图 | 首选镜头组织 | 人物/环境配合 | 何时不用 |
| --- | --- | --- | --- |
| 普通对话 | 中近景固定或极轻微跟移，维持受话对象视线 | 说者嘴部动作，听者视线反应 | 需要同步展示大范围行动 |
| 质问对峙 | 利用前后景位置和人物间距离制造压力 | 手指/下颌收紧，不必两人同时怒吼 | 剧情已进入高速打斗 |
| 发现秘密 | 先让角色视线锁定已有异常，再显露局部物件变化 | 角色停手、呼吸变化，局部反射增强 | 观众已在上一镜清楚看见信息 |
| 震惊反应 | 保持可读的面部景别，明确刺激来源 | 目光聚焦、轻微后撤 | 需要展现多人全身位置变化 |
| 能力觉醒 | 能量从可见来源聚集并产生身体/环境反馈 | 衣物、发丝、灰尘按作用方向响应 | 剧情未出现超自然机制 |
| 技能释放 | 用一个清晰动作轨迹和命中结果组织时间线 | 手势/武器、受击点和声光同期 | 需要多段复杂连击，应拆镜 |
| 追逐 | 保持横向运动方向与速度，适度跟拍 | 地面接触与背景视差 | 角色需要静止说长对白 |
| 人物出场 | 先展示人物与空间的比例、轮廓或局部动作 | 配合光源揭示面部或标志物 | 参考图要求近距离身份对齐 |
| 危险逼近 | 利用角色视线和已有环境的变化形成预告 | 门缝光、远处声音、脚步反应 | 设定没有可见的威胁来源 |
| 情绪释放 | 演员动作先改变，镜头可固定 | 呼气、松手、肩颈放松 | 信息焦点是外部物体 |
| 反转揭示 | 保持镜头内因果：人物注意→物体变化→反应 | 视线转移与动作同时发生 | 需要跨空间反打，应拆镜 |
| 场景建立 | 全景交代空间锚点与主体位置 | 已有灯光、天气、风、雾 | 本镜只是关键道具极特写 |

## 避免流水线同质化
在连续分镜里记录上一镜选择的景别与运动：不要每镜都低机位、缓推、环绕、发光或过度慢动作。相邻两镜若承担不同信息，优先通过视觉焦点和表演差异区分，而不是强行改变场景风格或摄影机轴线。
