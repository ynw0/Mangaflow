# 声音设计与 H3 时间轴

## 三层声音
1. `overall_soundscape` 写根据剧本、场景或用户要求应当持续听到的声音。没有这类声音时填 `N/A`。
2. 随动作发生或在特定时刻出现的声音，写在 `detailed_description` 对应的位置。
3. `non_diegetic_music`：角色听不到的配乐；必要时说明乐器、节奏、强弱和变化；没有则 N/A。

## 让声画同源
- 画内说话人的口型与 `(Sx)` 对应的原话和时刻一致。旁白、角色内心独白和无实体的网文系统，在说话人编号后使用 `says in an off-screen voiceover`，并在该段 `</d>` 后立即说明对应画面人物嘴唇保持闭合。Ref2VA 中已定义的主体沿用 `<Subject N>`，其他模式按实际角色或声源描述。现场人物在构图外开口时，写实际方向和听者。
- 声音的出现、变化和停止要符合剧情时序。
- 特效要有声音来源、力度与衰减；电弧是短促噼啪，冲击波是随冲击扩散的低频冲量，不能所有技能都用同一个雷鸣。
- 根据人物声线和本场表演安排语速与音色；`speechPolicy` 与 `voiceCast` 是可选的辅助资料，未指定语速不必另写。剧本需要保留的间歇、犹豫或换气随原台词安排。
- 用音区、共鸣或咬字区分角色。根据当前场戏安排台词结束的时刻、随后的反应，以及镜头结束前需要预留的时间。静默镜头省略语速。

依本场已有的动作、声源和环境安排听觉层次。人物据此作出反应的声响，写清何时传来以及谁听见。普通设备或画面变化仅在确有声响时写出声音。实际听感由成片质检核对。
