# 视觉特效：来源、动力学和环境反馈

## 特效的六个可观察要素
1. 来源：手心、地面符阵、武器刃口、裂缝、天空或已有设备，必须在场景中成立。
2. 形态：细丝、粒子、闪电弧、流体、火舌、光环、冲击波等，确定主形态，不全堆。
3. 轨迹：绕行、汇聚、喷射、扩散、下落；标明方向和起止位置。
4. 时间：从弱到强、短脉冲、持续燃烧、突然断电；时序符合镜头时长。
5. 反馈：光照影响皮肤/衣物/墙体，风压扬起尘土、吹动头发，碰撞出现碎屑和受力。
6. 收束：平息、残留光斑、碎粒落地、烟雾散去；结尾与 continuity_out 对齐。

## 常见效果组合（每镜按需选一个主机制）
| 类型 | 可执行表述方向 | 需要警惕 |
| --- | --- | --- |
| 能量聚集 | 手掌附近几点细光汇聚，形成稳定的小光团，近处衣袖受到微弱照明 | 凭空变成大范围爆炸 |
| 雷电 | 两个明确物体之间出现短促电弧，沿接触点分叉并熄灭 | 无限分叉使主体不可辨认 |
| 火焰 | 从燃料/法术源升起，火舌随气流偏转，近处边缘受暖光 | 产生与火源方向矛盾的光影 |
| 法阵 | 地面环状符纹逐段点亮，向中心收束，随后保持稳定 | 复杂符号改变批准的地面材质 |
| 冲击波 | 受击点向外传播一圈可见尘浪，布料随波前摆动 | 波前没有碰撞源，人物无反应 |
| 空间扭曲 | 局部背景边缘出现短暂光学弯折，随主体移动恢复 | 连带变形人物与身份资产 |
| 冰霜 | 从接触点向外蔓延细小晶体并形成霜层 | 一瞬间重塑整个场景结构 |
| 光点/星屑 | 少量粒子沿指定风向飘离，再逐渐暗下 | 数量失控遮挡人物脸部 |

## 玄幻技法并非默认配置
只有剧情确有技能、异象或超自然作用时使用；现实题材改用可信的灯光、烟尘、火花和物理反馈。锁住特效作用对象与参考图关系，禁止凭空添加法器、阵法或人物。

## 单镜头范例（内部设计，不是 H3 正文）
“灰白石体裂隙中冷蓝微光从内部缓慢增强→托盘表面出现短暂蓝色反射→光线沿裂隙向中心收拢；摄影机固定近景，最后保留裂隙原有形状。”

## 特效机制与同场反馈

| 机制 | 起点、作用、末态 | 选择与失败边界 |
| --- | --- | --- |
| 定向光束 | 短暂蓄光沿装置轴线出射，命中指定表面后局部过亮，反射随光束收窄而恢复 | 适合强调命中；侧看传播轴，避免整屏曝光抹去落点 |
| 缠绕束缚 | 光丝从已设源头绕向前臂或武器，接触后张力方向明确，受力方只在接触后偏移，末态保留束缚位置 | 适合控制；避开脸与关节，以免形体变形 |
| 屏障裂解 | 屏障先有稳定轮廓，碰撞点先暗再出现向外扩展的裂纹，碎光沿断裂边缘落下，防御开口露出 | 适合交代破防；必须留出读得到的碰撞点与开口 |
| 火焰点燃 | 火源接触可燃表面后，火舌沿表面与气流扩展，近处受暖光，烟从热区升起 | 火与烟按空间层次分开，人物反应要有热源来向 |
| 电弧跳跃 | 发射点与导体的接触处出现短弧，再沿最近导电边缘分叉后熄灭，局部反光与噼啪同期 | 主弧方向优先，多处分支会抢走出手点 |
| 冰封 | 接触点出现薄霜，沿材质表面向一侧蔓延，停在剧情要求的边界，邻近结构保持形状 | 用局部近景交代材质变化，避免全景一闪即换材质 |
| 烟尘遮蔽 | 灰尘由受击地面掀起，薄层先贴地扩散，稍后颗粒下落，主体关键轮廓在可读范围内 | 若需要始终看见手或命中点，控制遮挡范围 |
| 爆裂碎片 | 从受力部位先裂开，碎片向外散并逐步受重力下落，余下部分停在明确破损状态 | 适合结构破坏；保留场景参照，免于看成整体消失 |
| 空间折射 | 指定边界内的背景直线局部弯折，边界随能量移动，经过后背景几何恢复 | 用已有建筑直边作参照，角色轮廓应在折射范围外 |
| 残影消散 | 主体沿真实路径运动，淡薄残影在刚经过的位置依次衰减，最后只保留清楚的实体轮廓 | 适合已设定的高速异象，防止误读为复制角色 |
| 吸收或收束 | 细粒从周围沿收缩路径回到源头，局部亮度降低，残余反馈随之停止 | 与爆炸向外扩散区分，末态遵照后续镜头 |

**格挡案例**。若剧情要求剑弧击中盾面后被抵消，用斜侧中全景看到刃口、弧形前缘和盾沿。弧体由剑刃发出，亮弧前缘领先，盾面被击中后沿接触点出现一圈短反光，握盾者脚跟滑半步，弧体解成少量光点消失。若剧本要求穿透，才让能量在防御后方继续。
