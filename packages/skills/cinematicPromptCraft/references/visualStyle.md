# 美术风格转化为画面事实

`production_profile` 和批准资产是风格真源。本文件提供可观察的表现方法，不是自动切换风格的命令。

| 设定风格 | 应描述的可见特点 | 常见跑偏 |
| --- | --- | --- |
| 国风 3D 动画 | 稳定的角色比例、服装褶皱、细致材质、明确场景纵深、适度非写实光照 | 面部忽然变成真实人像 |
| 二维动画/漫剧 | 平涂层级、线条宽度、赛璐璐阴影、角色动作关键姿态 | 随机增加照片级皮肤毛孔 |
| 写实电影 | 自然肤色和物理材质、来自场景的布光、合理镜头透视 | 塑料质感、过强光晕 |
| 水墨 | 墨色浓淡、宣纸肌理、形体留白、笔触运动规律 | 人物细节被溶解而丢失身份 |
| 赛博朋克 | 人工光源、材质反射、城市层级和暗部层次 | 到处新增霓虹广告和文字 |
| 厚涂插画 | 大色块、可见笔触、局部高光、轮廓统一 | 镜间随机切成3D渲染 |
| 定格/纸艺 | 实体材料边缘、关节式运动、分层景深、手工材质 | 无缘由混入真人摄影 |

## 风格一致性
- 角色、服装、物体比例和镜头光照必须遵守当前设定；风格形容词不能覆盖身份锁。
- 影视摄影知识可用于动画构图，但镜头运动和动画帧表现应服从当前生产设定。
- 只有用户明确改变风格或项目设定发生版本变化时才重新设计主风格；不同镜头可变化景别和色彩重心，不可随机换材质语言。
