# 专业对白精修

## 定位

这是**编剧阶段的一次独立表演性改稿**，不是新的导演、审稿系统或完整剧本重写。由现有 `subAgent` 以 `role: "story"` 执行，沿用编剧模型与思考等级。使用前按 `skillOperator` 的 `list → read` 读取本技能；不对一般聊天、资产、分镜、视频提示词自动调用。

输入：本次完整场戏及必要的相邻场次、当场人物关系与各自目的、已批准剧情事实/关键原话/角色口吻、时长与本轮限制。缺前后文时先读取，不凭一句孤立台词改写人物。改写前区分**可以改的表述**与**明确锁定的原话**；后者只指出问题，不擅自替换。

用户点名要求修改的旧句子属于本轮改稿范围。用它定位问题，给出能和上下句自然相接的改稿。保留尚有效的原意、剧情事实和人物关系。

## 实际怎么改

不要把“自然对白”理解成每句话都短、都有冲突、都立即推动情节。熟人之间会说废话，陌生人会绕弯，紧张时可能突然问一件小事；这类交流若让人物关系成立，可以留下。先判断整场戏像不像人真正经历的交流，再决定要不要动其中几句。

1. 先连读场戏中的动作和对话。逐位人物想清楚：此刻看到、听到、知道什么；想让谁做什么；有什么不愿承认；对方上一句话或一个动作怎样影响他的回答。人物可以误解、回避、嘴硬、突然转移注意，也可以直接说清楚，选择必须由眼前情境决定。
2. 只找确有问题的地方：角色重复解释画面已表现的动作；替作者总结结果或补说双方早已知道的背景；每句都带职业术语、数字或口头禅；多人都用同一种断句和金句；突发事故却忽略人的即时反应；回话与前句没有实际联系。必要的确认结果、施压、职业汇报、系统播报不误判。
3. **先改接话和反应，再改措辞。** 可以将一句话换成短促的打断、一次有因的沉默或与台词相连的小动作；不能为了“活人感”强行加语气词、段子、闲聊、口吃、哭喊或省略号。角色长短句应随状态变化，不是人人都说短句。
4. 只修问题所在的连续对话片段，保留场次编号、人物、地点、时间、事件顺序、因果、关键道具和已确定的胜负、代价、结尾。涉及对白关联动作时连同动作一起给替换建议；不得让人物凭空知道消息或产生新决定。保留必要的专业词和原定基调。注意口播时长，不为精修增加无法拍完的台词。
5. 对照原稿连读修改后的整段对白。核对说起来是否顺口、人物为什么这样接话、观众第一次听能否认出所指和关键信息。发现拗口叫法、病句或语义偏移时，改有问题的字句并保留原意。已经自然准确的说法直接保留。

## 对照示例取材

用当前场戏的原话和建议改法做对照。交代听者刚听到什么、看见什么，以及改动怎样改善接话或理解。

## 交付和对照

只返回本轮问题片段，格式简洁：
- `场次/位置`：原对白及关联动作（必要时连同上一句）
- `问题`：具体哪一处不像人物现场交流
- `建议替换`：完整的连贯接话片段及必要动作，不是孤立漂亮句子
- `前后对照`：为什么更符合人物动机、信息边界和情绪，原剧情事实是否不变

将建议提交给当前编剧/主 Agent，由其检查剧情事实、角色关系、时长及前后接话后**局部采纳并回读剧本节点**。不以示例的句长、反问或打断次数判好坏；场戏整体自然但局部措辞平常，也可以直接通过。若建议不能改善或改变了锁定事实，保留原稿或仅修受影响处；不无限重写，不自动启动额外审稿 Agent。**对白在剧本通过并完成既定确认后才锁定**，分镜只抄锁定原话；需要再改时先返回剧本阶段。

不输出整集重新生成稿，不直接写画布，不修改用户当前运行的其他任务。
