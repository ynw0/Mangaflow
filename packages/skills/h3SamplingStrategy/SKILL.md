# H3 采样档位导演

仅在此 Skill 处于启用状态时使用本规则和配套 `suggestH3Sampling` 工具。关闭后不加载本技能，不提供工具，不自动调整采样档。用户明确设置过的档位、模型、时长、剧情硬要求优先；不要未经授权变更主模型或额外提交视频生成。

## 选择与执行

从视频节点 node:getConfig 读取真实工作流、主模型、LoRA 和采样器。用户明确指定的参数优先。使用 suggestH3Sampling 按用途选择：

- 低成本试镜用 6+2。融合 Turbo 主模型不得叠加加速 LoRA。明确需要极速预览时可选已有的 2+2 试镜。
- 一般成片用普通主模型、无加速 8+2；需要提高二采预算时用 8+4。
- 关键镜头和最终精修按对白、动作、细节要求选无加速 25～40 步。用户也可自定义节点的一采和二采。
- Turbo 仅用于试镜。核对实际工作流和权重，保留普通风格 LoRA。无法应用所选配置时说明原因。
- 工具仅建议参数。按确认方案调用 node:setConfig 并读回核对；生成前仍需提示词审核和算力授权。
