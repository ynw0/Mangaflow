# H3 采样档位导演

仅在此 Skill 处于启用状态时使用本规则和配套 `suggestH3Sampling` 工具。关闭后不加载本技能，不提供工具，不自动调整采样档。用户明确设置过的档位、模型、时长、剧情硬要求优先；不要未经授权变更主模型或额外提交视频生成。

## 五个档位

| 档位 | 一采 + 二采 | 何时选 | 注意事项 |
| --- | --- | --- | --- |
| 极速试镜 | 2+2，共4步 | 构图、动作方向、镜头方案的快速测试 | 使用安装列表中的 `minimax_h3_ref2v_turbo_4step_v1.0_768p_comfyui_bf16.safetensors`；不是正式成片默认档，不将 TaoMate 3step 当成等价4step |
| 快速均衡 | 4+4，共8步 | 普通对白、常规动作、一般正式剧情镜头 | 使用已验证兼容的8step加速 LoRA，二采保留较多预算 |
| 快速结构优先 | 6+2，共8步 | 复杂动作、空间结构、机械展开的实验对比 | 一采多步不保证比4+4更好，应结合同种子、同参考 QC 对比 |
| 普通高质量 | 合计25～40步，默认20+5 | 关键剧情、人物特写、最终成片和复杂结构 | 关闭加速 LoRA，保留兼容的普通风格 LoRA；可由 Agent 根据镜头自定义30/35/40，不能高于40，步数更高不保证必然更好 |
| 融合 Turbo | 4+4，共8步 | 主模型已确认融合 Turbo 的快速批量生产 | 不能叠加加速 LoRA；文件名含 turbo 不是充分证据 |

## 智能决策与执行

1. 只对 ComfyUI 的 H3 Ref2VA 二采工作流启用；云视频、首尾帧、专用加速输出头/PDD/PTD/HyperFlow 不自动套用。
2. 先用**画布视频节点** `node:getConfig({refreshComfyChoices:true})` 读取所选工作流、真实 checkpoint、LoRA、可选 sampler/scheduler、当前附加 LoRA；不要猜本机模型文件是否存在。
3. 结合当前镜头合同与用户要求判断 `phase`：`preview` 只做试镜；`normal` 一般正式镜头；`motion` 结构动作；`key` 重要剧情；`final` 最终精修。用户指定档位先于自动推荐；不要偷换成更低档。
4. 将从节点读取的真实信息传入 `suggestH3Sampling`。对 `checkpointKind` 和 `compatibilityConfirmed` 必须有可核对依据；文件名、手动加速 LoRA 标记不等于兼容。正式8步未经验证则降级普通25步；4步可以明确作为实验，但必须披露风险。
5. 工具只做建议，不修改节点、不提交生成。对于 `ready` 或被授权的 `experimental`，用 `node:setConfig` 一次写入返回的 `setConfig` 参数；然后用 `node:getConfig` 再次确认每个字段。若工具为 `blocked`，说明具体阻碍，不假设已经适配。
6. 修改设置后，先重新核对 `node:getPromptContext` 的审核版本以及 `draftVideoPrompt` 已审稿的适用性；只有完整生产授权、审核与参考齐备时才能启动 `node:generate`。
7. QC 未通过时先分析参考、提示词、动作逻辑、连续性、声音及二采设置的根因；不能一味加步数或自动重复生成。已生成任务复用 generationId 查询，不重复提交。

**试镜与正式成片分开**：4步可很快验证镜头方向，但动作错误、人物身份、表情和同期声音尚不能作为正式质量证明。正式镜头优先已验证兼容的8步；关键镜头用25～40步。若没有可靠兼容证据，不得仅因为列表中出现加速LoRA就自动启用。

**节点 UI 只展示预设选择。** Agent 在实际运行期间允许经工具校验自定义25～40步一二采分配；用户选定的设置不能被智能策略静默覆盖。执行完留下具体档位、LoRA、采样器和原因以便复现。
