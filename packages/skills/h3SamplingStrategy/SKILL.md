# H3 采样档位导演

本技能只决定经过确认的采样配置，不对人物对白、剧情节奏、表情或画面风格附加模板。采样参数必须实际写入并回读；不能把选择“高质量档”当成提示词需要更多夸张形容词或镜头动作的理由。

仅在此 Skill 处于启用状态时使用本规则和配套 `suggestH3Sampling` 工具。关闭后不加载本技能，也不提供对应工具或自动调整采样档位。用户明确设置过的档位、模型、时长、剧情硬要求优先；不要未经授权变更主模型或额外提交视频生成。

## 选择与执行

从视频节点 node:getConfig 读取真实工作流、主模型、LoRA 和采样器。checkpointKind 使用节点返回的已确认类型，unknown 时先确认权重类型。用户明确指定的参数优先。使用 suggestH3Sampling 按用途选择：

- 低成本试镜用 6+2。融合 Turbo 主模型不得叠加加速 LoRA。明确需要极速预览时可选已有的 2+2 试镜。
- 一般成片的低步数实验档用普通主模型、无加速独立双采 8+2；需要提高二采预算时用 8+4。二采降噪0.25，低步数音画质量尚需验证；重视同期声时优先质量档。
- 关键镜头和最终精修默认完整一采32步＋独立二采10步，二采降噪0.25。这组配置已用于无加速底噪对照。显式指定 qualitySteps 时仍按25～40总步数分配；其他组合尚需验证。用户也可手动选择采样方式和两个阶段的步数。
- Turbo 仅用于试镜，保留原分段双采，不使用独立二采降噪参数。核对实际工作流和权重，保留普通风格 LoRA。无法应用所选配置时说明原因。
- 工具仅建议参数。按确认方案调用 node:setConfig 并读回核对；仅调整采样参数时保留提示词正文；生成按已有算力授权执行。
