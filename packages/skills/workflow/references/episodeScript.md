# 逐集剧本

需要完整场次正文（场号、人物、动作、对白）时使用本文件；镜头级合同仍以 [story-planner.md](story-planner.md) 为准。画布落点见 [canvas-use.md](canvas-use.md)。

不依赖已断链的旧 knowledge（如 scriptCraft / narrativeGenres）；类型节拍与表演方法写进本集「创作决策」文本节点，或沿用用户已确认的改编策略。

## 输入

- 已确认的项目配置、故事骨架、分集意图与 [adaptationStrategy.md](adaptationStrategy.md)
- 当前集对应原文与事件，以及上一集已确认剧本和结尾角色状态
- 本次明确要处理的集号；已有本集剧本、用户修改意见和确认记录

## 执行方法

1. 回读输入和当前进度，定位尚需编写或修改的指定集；每次聚焦一集。
2. 提取本集来源、戏剧功能、场景核心、删减决定及结束点；终集按已确认结局收束，不硬造下一集钩子。
3. 衔接上一集的时间、地点、角色关系、外观和关键道具状态；不把所有已完成剧本重新生成。
4. 组织具体场景，让动作、对白和场景变化推动剧情；心理描写转成可表现的行为或必要 OS/VO。
5. 写明场号、地点、时间/内外景、本场人物、动作与表情、台词、必要声音和转场。
6. 按时长目标估时：对白可按语速参考，动作和停顿另行计入，不能把字数换算当实测。时长跟 `production_profile` 与用户约定走。
7. 检查本集新信息、冲突变化及结尾期待；镜头技术设计留给 [directorPlan.md](directorPlan.md) 与成片阶段。
8. 修改本集时只更新指定内容，并复核与上一集、下一集大纲的衔接。
9. 行动场明确目标/阻碍/选择/结果；日常、过渡和留白场记录关系、时间、信息或情绪的实际作用，不强造阻碍。保留有功能的沉默和日常。

## 写入剧本画布

默认在剧本画布维护；每集一个清晰可定位的正式剧本节点。

- 节点标题建议为「第001集剧本｜集标题」；同一集已有节点时原位修改，不得把「修订版」「定稿」当成新的一集。
- 已确认的剧本节点作为该集制作来源；分集画布记录真实来源定位，不另建一套剧本库。
- 同画布「第001集创作决策」文本节点保存本集情绪/信息变化、伏笔兑现、关系距离变化、关键声音及估时依据；不把分析和模型参数夹进剧本正文。
- 正式剧本把上述决定兑现为动作、对白、沉默、必要声音和转场。

剧本正文最少包含：

```text
作品名 EP001：集标题
目标时长 / 画幅 / 风格
剧情梗概：本集主要冲突、关键转折和情感变化
1-1 场景名 日/内
人物：本场实际出场人物
△具体环境、动作、表情及必要道具
人物名：台词
OS/VO：必要的内心独白或画外音
转场与下一场；本集结束点
```

## 确认与交接

- 当前集与已确认大纲和策略一致；无擅自增加、漏掉或重写其他集。
- 场号、人物、时间地点明确；动作可表现；台词保持角色口吻。
- 写入后回读完整正文，展示本集摘要，**等待用户明确确认**后再推进下一集或下游。
- 不把完成通知、用户沉默或内部自检通过当作确认。
- 确认后可进入资产规划 / [directorPlan.md](directorPlan.md)；需要镜头合同时走 [story-planner.md](story-planner.md)。
