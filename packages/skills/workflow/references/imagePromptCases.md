# 高质量原画提示词维度清单（Qwen / ComfyUI）

版本：1.1.0（2026-11-19）。不提供可整段粘贴的英文成品示范句；只给维度与验收问题。使用时严格遵从当前角色/场景/道具提示词合同、正负面节点和已批准的身份结构。

## 参考来源
- Qwen-Image-2.1 官方 T2I / Edit Prompt Rewrite（GitHub QwenLM/Qwen-Image-2.1）
- Runway 官方 Image Prompting / Image References Guide

这些是写法依据，不证明本机 ComfyUI 工作流已生成过相同效果。

## 用法
根据 asset_type、当前任务 T2I/edit、已批准主图、应保留/可变更字段，选取最多 1–2 组维度自检。颜色、人物、车辆、机械部件必须以当前 canonical 为准。先有明确的来源、大小、外形，再谈画面修饰。正面提示词按当前工作流规则，仅写希望可见的状态。

## I01｜角色设定：可追踪身份
tags: character; t2i; turn-around; consistency
维度：全身/半身景别 · 中性站姿与朝向 · 发型与脸型可辨特征 · 服装层次与口袋等细节 · 手足是否入画 · 主光方向与肤质/缝线可读 · 中性背景与人体比例。
质检：脸与衣装、手数、脚部完整、身高比例可读；三视图按对应 workflow 网格规则，不把单图描述硬搬成拼版。

## I02｜载具/道具基准：真实重量
tags: prop; vehicle; t2i; 3/4-view; physical-scale
维度：真实尺度与视角 · 接地接触点与投影 · 漆面/磨损落在受力部位 · 主光在曲面上的高光走向 · 整车/整物入画。
质检：同一主体与部件数量、比例、接地、材质可信；已批准图不得换型/换色；负面禁忌走 negative_constraints。

## I03｜机械母版：静态结构清晰
tags: prop; mechanical; t2i; identity-lock; geometry
维度：俯视/斜视等能看见安装点的视角 · 对称或成对模块的间距与中线关系 · 铰链/凹槽与主体连接处可见 · 收纳态 vs 展开态边界清楚。
质检：该视角能核对安装点、对称与收纳；看不见的侧面由其他视角验收。

## I04｜编辑任务：只动已有部件
tags: prop; edit; preserve-identity
维度：底图视角与已核验结构 · 要移动的部件名称与运动方向 · 露出宽度/行程是否对称或符合设定 · 须保留的机位、主体位置与材质纹理。
质检：视角未漂；只改声明的部件；多图输入时按实际槽位分配用途。
