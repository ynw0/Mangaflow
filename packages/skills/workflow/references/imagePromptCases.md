# 高质量原画提示词维度清单（Qwen / ComfyUI）

版本：1.1.0（2026-11-19）。不提供可整段粘贴的英文成品示范句；只给维度与验收问题。使用时严格遵从当前角色/场景/道具提示词合同、正负面节点和已批准的身份结构。

## 参考来源
- Qwen-Image-2.1 官方 T2I / Edit Prompt Rewrite（GitHub QwenLM/Qwen-Image-2.1）

## 用法
根据 asset_type、当前任务 T2I/edit、已批准主图、应保留/可变更字段，选取最多 1–2 组维度自检。颜色、人物、车辆、机械部件必须以当前 canonical 为准。先有明确的来源、大小、外形，再谈画面修饰。正面提示词按当前工作流规则，仅写希望可见的状态。

## I01｜角色设定：可追踪身份
tags: character; t2i; turn-around; consistency
维度：全身或半身景别、自然站姿与朝向、能够辨认的发型和脸型特征、服装层次及口袋等细节、手脚是否进入画面、主光方向、清晰可辨的皮肤质感与服装缝线、中性背景和人体比例。
质检：检查脸部和服装、手的数量、脚部是否完整，以及身高比例是否清楚。三视图按照对应 workflow 的网格规则制作，不直接将单张图的描述套用到拼版中。

## I02｜载具/道具基准：真实重量
tags: prop; vehicle; t2i; 3/4-view; physical-scale
维度：真实尺度和观察视角、物体与地面的接触位置及投影、受力部位的漆面和磨损、主光在曲面上形成的高光走向，以及车辆或物体是否完整进入画面。
质检：确认主体一致，部件数量、比例、与地面的接触关系及材质合理。已经批准的图不得更换造型或颜色。需要排除的内容填写在 negative_constraints 中。

## I03｜机械母版：静态结构清晰
tags: prop; mechanical; t2i; identity-lock; geometry
维度：采用俯视、斜视等能够看见安装位置的视角；交代对称部件或成对模块的间距及其与中线的关系；确保铰链、凹槽与主体的连接位置可见；明确区分收纳状态与展开状态。
质检：确认当前视角能够核对安装位置、对称关系和收纳状态；无法看见的侧面由其他视角验收。

## I04｜编辑任务：只动已有部件
tags: prop; edit; preserve-identity
维度：底图的视角与已经核验的结构、需要移动的部件名称和运动方向、露出的宽度及运动行程是否对称或符合设定，以及必须保留的机位、主体位置和材质纹理。
质检：确认视角没有发生偏移，只有明确指定的部件发生变化。使用多张输入图片时，按照实际槽位分配各图的用途。
